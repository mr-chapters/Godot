# Contributing

Help make game development easier to learn.

## Lesson checklist
- Explain the learning goals and prerequisites.
- Explain concepts in plain language, not just jargon.
- Include a complete Godot 4 example and describe the required node/scene setup.
- Explain important lines, expected behaviour, and how to run the example.
- Include common mistakes, practice tasks, and a knowledge check.
- Link to official documentation and test snippets in Godot when possible.

Use clear names, consistent indentation, keyboard-accessible UI, and accurate claims. Do not include secrets or copy long passages from other tutorials. The website does not run GDScript in the browser; examples must be run in Godot.
