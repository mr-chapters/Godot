# Contributing

Help make GDScript and Godot easier to learn.

This repository is a **written course made of Markdown lessons and project guides**, not a website.

## Before contributing

- Read the lesson before editing it.
- Keep explanations beginner-friendly and technically accurate.
- Target Godot 4.x unless a lesson clearly says otherwise.
- Test code examples in Godot whenever possible.
- Prefer official documentation for API details and version-specific behaviour.

## Lesson checklist

- Explain learning goals and prerequisites.
- Introduce concepts in plain language before using jargon.
- Include a complete, focused example and describe the required node/scene setup.
- Explain important lines and expected behaviour.
- Include common mistakes and practical exercises.
- Link to the relevant official Godot documentation.
- Check Markdown headings, code fences, and links.
- Avoid claiming code was tested unless it actually was.

## Good contributions

Corrections, clearer explanations, additional practice tasks, tested examples, typo fixes, and new project guides are welcome. Open an issue first for large changes so the course stays organised.

## Originality and respect

Write explanations in your own words. Link to external resources rather than copying large sections of tutorials. Do not commit credentials, API keys, private data, or unrelated build artifacts.
