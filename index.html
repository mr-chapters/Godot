HOW TO GET GOOD

Don't just watch.
Experiment.

Type code, run it, change one thing, and explain the result in your own words.

  1. Predict

    Decide what the code should do before you run it.

  2. Type it yourself

    Notice punctuation, indentation, names, and node setup.

  3. Change one thing

    Observe what changes and what stays the same.

  4. Read errors as clues

    Check the first useful error, line number, spelling, types, and scene paths.
