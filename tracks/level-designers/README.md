# 🗺️ Level Designers' Book — Build Maps That Play Well

Learn to plan, block out, build, light, test, and polish maps for 2D and 3D Godot games. A good map is more than decoration: it teaches the player where to go, creates decisions, supports pacing, and keeps the route readable.

## Chapters

1. [Plan a Map Before Building](01-plan-a-map.md) — goals, player verbs, flow, and paper layouts.
2. [Blockouts, Scale, and Navigation](02-blockouts-scale-and-navigation.md) — greyboxing, landmarks, routes, and movement tests.
3. [Build 2D Maps with TileMaps](03-build-2d-maps-with-tilemaps.md) — tile sets, layers, collisions, terrain, and autotiling.
4. [Build 3D Levels](04-build-3d-levels.md) — modular kits, grid snapping, terrain, rooms, and verticality.
5. [Lighting, Landmarks, and Environmental Storytelling](05-lighting-landmarks-and-storytelling.md) — visual hierarchy and clues in the environment.
6. [Playtesting, Optimization, and Final Handoff](06-playtesting-optimization-and-handoff.md) — test routes, fix confusion, profile, and document.

## Recommended workflow

**Plan → Blockout → Playtest → Revise → Art pass → Test again.** Do not spend hours decorating a route before you know that it is fun and navigable.

## Graduation challenge

Build one compact map with a start point, a clear goal, a shortcut or optional route, one hazard, one landmark, and a checkpoint. Give a new player no verbal directions and observe whether they can reach the goal. Fix the map based on what they actually do.
