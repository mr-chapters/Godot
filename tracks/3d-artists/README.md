# 🧊 3D Artists' Book — From Shapes to Game-Ready Assets

**Who this is for:** learners who want to model, texture, light, and prepare 3D assets for Godot. Start with simple shapes, prioritise readability, and learn a repeatable export workflow.

## Study method

For each chapter, make a small test asset, export it, open it in Godot, and compare the result with your intention. Keep source files, exported files, textures, and notes organised. Test scale and silhouette before polishing a model.

## Graduation challenge

Create a small prop set: one hero prop, two variations, one material variation, and a simple test scene in Godot. Include a handoff note stating scale, file format, texture files, licence, and known limitations.
