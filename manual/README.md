# Godot Manual Pack

This folder is a practical reference manual for building games and interactive projects with Godot 4. It complements the step-by-step lessons in `lessons/` and the guided builds in `projects/`.

## Manual sections

- [Audio and sound design](audio/README.md) — make, edit, import, play, mix, and organise sound for games.
- [Pixel-art workflow](pixel-art/README.md) — plan pixel-art assets and import them cleanly.
- [Project production checklist](production/README.md) — organise, test, export, and share a Godot project.

## How to use this manual

1. Read the section that matches the problem you are solving.
2. Follow the steps in a small test project before changing a large game.
3. Copy code examples into a script attached to the node described in the instructions.
4. Confirm node names, input actions, resource paths, and Godot version.
5. Use the linked official documentation when a setting or API behaves differently in your version.

The code and guidance primarily target **Godot 4.x**. Editor labels and features can change between releases, so always check the official documentation for your installed version.
