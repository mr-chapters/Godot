## The basic workflow

**Design → create or source → edit → export → import → play → mix → test → check the license.**

You do not need expensive software to begin. Start with short, clear sounds and a small set of files. A good click, pickup, jump, error, and success sound can make a prototype feel responsive.

## Important licence rule

A sound being free to download does not automatically mean it can be redistributed or used commercially. Check the licence on the exact sound or pack, keep any required attribution, and save a copy of the licence details with your project. The resources in this manual are starting points; their terms can change.
