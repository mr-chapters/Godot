# 02 — Sound-Making Apps and Free Asset Links

These tools and libraries can help you create sounds yourself or find sounds for a Godot project. Open each source and check its current terms before using or redistributing files.

## Make your own sounds

- [Audacity](https://www.audacityteam.org/) — record, trim, fade, normalise, and edit audio.
- [ChipTone](https://sfbgames.itch.io/chiptone) — browser-based tool for generating retro-style sound effects.
- [jsfxr](https://sfxr.me/) — browser-based retro sound-effect generator.
- [Bfxr](https://www.bfxr.net/) — classic tool for generating arcade-inspired effects; check the current download and platform details.
- [LMMS](https://lmms.io/) — music production software for composing and arranging music.
- [Bosca Ceoil Blue](https://yurisizov.itch.io/boscaceoil-blue) — approachable music-making tool for game-style melodies; check its current platform and licence details.

## Download sound effects

- [Kenney — Impact Sounds](https://kenney.nl/assets/impact-sounds) — impact and foley-style effects; the asset page identifies the pack as CC0.
- [Kenney — all assets](https://kenney.nl/assets) — browse game asset packs, including audio.
- [Kenney — licence and FAQ](https://kenney.nl/support) — explains Kenney's asset licensing and attribution guidance.
- [Godot Asset Library: Kenney Interface Sounds](https://godotengine.org/asset-library/asset/794) — interface sound pack prepared for Godot; listed as CC0.
- [Godot Asset Library: Kenney UI Audio](https://godotengine.org/asset-library/asset/796) — UI sounds prepared for Godot; listed as CC0.
- [OpenGameArt](https://opengameart.org/) — community game assets. Licences differ by item, so check each asset page carefully.
- [Freesound](https://freesound.org/) — community sound library. Licences differ by recording; check the individual file's terms and attribution requirements.

## Which tool should I start with?

- **Want retro effects quickly?** Try ChipTone or jsfxr.
- **Want to trim a recording or fade a sound?** Use Audacity.
- **Want music?** Try LMMS or Bosca Ceoil Blue.
- **Want ready-made effects?** Start with Kenney's sound packs.
- **Want a specific real-world recording?** Search a sound library and inspect the individual licence.

## Licence checklist

Before adding a file to a game, answer:
- Is commercial use allowed if the game might be sold?
- Is attribution required?
- Can the file be modified?
- Can the file be redistributed inside a game or asset pack?
- Does the licence require the original author or licence to be included?
- Is the asset actually covered by the stated licence, or is it a user upload with separate terms?

Do not assume every item on a community library has the same licence. Prefer clearly documented CC0 or other licences that match your intended use, and keep a `THIRD_PARTY_ASSETS.md` file in your game project.
